# modules (files) that define each and the reason it is not a copy: the same verb on

# one shared kernel (`frequency_correlation`, `ase_psd`). Reviewed on 29-30 October
# 2026 and again on 3 November 2026 (no copy left among them).

# `python3 tools/api_index.py --duplicates --check` (in `just check`) fails on a name
# defined in several modules that is not listed here, and on a listed name defined in
# more modules than its count: factor the code into one kernel, or add the name (raise
# its count) with the reason it is not a copy. It also fails when a count is too high
# (lower it, or remove the name once it is defined once).
