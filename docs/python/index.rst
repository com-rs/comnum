comnum
======

**Link-level simulation of digital communication systems, wireless and optical.**

``comnum`` is the Python interface of `comnum <https://github.com/com-rs/comnum>`_:
the blocks of a digital or optical link — sources, constellations, pulse shaping,
channels, fibre propagation, devices, receiver DSP and metrics — implemented in Rust
and driven from Python with NumPy arrays. Monte Carlo campaigns run on every core with
reproducible random streams, and their results come with confidence intervals.

.. highlights:start
.. highlights: generated by tools/highlights.py, do not edit

- **Lightweight**: one run-time dependency in Python (numpy), 9 direct crates in Rust and no C, C++ or Fortran library to build; 27 MB installed with its dependencies (the benchmark's environment: komm 22 MB, OptiCommPy 321 MB, Sionna 1004 MB).
- **Fast**: compiled Rust, Monte Carlo runs on every core; on one CPU thread, the links of the benchmark take 2.1 to 33 times as long with komm, 2.3 to 4.7 times as long with OptiCommPy and 1.1 to 7.4 times as long with Sionna as with comnum.
- **Safe**: ``unsafe`` code forbidden in every crate, invalid inputs are errors (one error type), results independent of the thread count; 757 unit tests, 205 validation tests, 284 Python tests.
- **Validated**: compared with 142 papers, standards and reference tools (88 fully reproduced, 50 partly), 123 inconsistencies found in them; 111 validation cards rerun a comparison without the paper.

The details, and how these numbers are produced: :doc:`why`.
.. highlights:end

.. code-block:: python

   import comnum

   rng = comnum.Rng(1)
   c = comnum.Constellation("qam", 16).normalized()
   bits = comnum.bits(4 * 100_000, rng)
   y = comnum.awgn_ebn0(c.map_bits(bits), 10.0, 4, rng)
   comnum.ber(c.demap_bits(y), bits), comnum.theory_ber(16, 10.0, "qam")
