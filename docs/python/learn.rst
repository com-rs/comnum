Learn
=====

Two ways in, both written as programs that run:

- :doc:`auto_basics/index`: a short course in digital communications, from bits and
  symbols to synchronisation and equalisation, each chapter a script that calls the
  functions of comnum;
- :doc:`auto_tutorials/index`: how to use comnum itself, from a first link to chains,
  Python blocks, declarative specifications, profiling and measured signals.
