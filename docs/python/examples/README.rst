Gallery
=======

What ``comnum`` can do, in runnable scripts: from a constellation to a complete
DVB-S2 or 5G NR receiver, from a single fading branch to large MIMO, from the
split-step Fourier method to a WDM link with Raman amplification, and down to
measured radio recordings and a modem that sends text through a loudspeaker. Every
figure of this page is produced by its script when the documentation is built, and
every script runs as is.

the published points; the comparisons with the literature are gathered in
