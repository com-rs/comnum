comnum playground

Docs GitHub PyPI

A comnum specification is a YAML file: a grid of conditions, a link as a list of blocks, metrics and a stopping rule. Pick one, edit it, press Run: the Rust engine, compiled to WebAssembly, runs the Monte Carlo campaign in your browser, on one thread, with the seeds and results of comnum run. The validation specifications draw the published points of their reference over the simulated curve.

      with pip install comnum (comnum.run_spec) or
      cargo install comnum-spec (comnum run spec.yaml), on every core.
