A specification is a YAML file: a grid of conditions, a link as a list of blocks, metrics and a stopping rule. Pick one, edit it, press Run: the Rust engine, compiled to WebAssembly, runs the Monte Carlo campaign in your browser, on one thread, with the seeds and results of comnum run. The validation specifications draw the published points of their reference over the curve.

The same files run on every core of your machine with pip install comnum or cargo install comnum-spec. MIT OR Apache-2.0. CodeMirror and Plotly come from a CDN; the simulation never leaves your browser.
